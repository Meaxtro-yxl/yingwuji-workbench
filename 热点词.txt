# 热点词 · 决定「热点」页留哪些条目
# 语法借自 TrendRadar：
#   空行分组，组内任一词命中就留
#   /正则/    正则，不分大小写
#   +词       这一组必须同时有这个
#   !词       这一组排除含这个词的
# [GLOBAL_FILTER] 下的词，任何组命中了也丢
# 改完点热点页的「刷新」就生效（改 配置.js 的 feeds 要重开应用）

[GLOBAL_FILTER]
融资
财报
股价
发布会
裁员
降薪
招聘
诉讼

[WORD_GROUPS]
# 现在没有启用任何组，热点页会是空的——这是故意的：先按你的赛道写词。
# 把下面几行的行首 # 去掉，改成你的词就能用。

# 第一组：核心词，命中任意一个就留
# /你的关键词1|你的关键词2/
# 你的关键词3

# 第二组：两个词必须同时出现（+ 开头）
# +行业词
# +方法词

# 第三组：这组排除某些内容（! 开头）
# !广告
